# 04_VISUAL_DIRECTION.md

## Visual theme
**Editorial Technical Case Study**

## Karakter visual
- modern
- premium
- teknis
- tenang
- kuat di typography
- berbeda tanpa terasa aneh

## Prinsip desain
1. Typography leads.
2. Layout breathes.
3. Projects look like evidence, not posters.
4. Metrics and technical notes carry visual weight.
5. Asymmetry is allowed, chaos is not.
6. Minimal decoration.

## Layout rules
- Gunakan 12-column grid di desktop.
- Hero boleh 7/5 atau 8/4 split.
- Featured projects menggunakan pola editorial bergantian.
- Mobile harus tetap satu kolom yang bersih.

## Typography
- gunakan sans-serif yang kuat untuk heading dan body
- gunakan mono font untuk label kecil, system notes, metrics, dan architecture tags
- headline besar, padat, tegas
- panjang paragraf harus terbatas agar mudah dibaca

## Spacing
- section spacing besar
- card spacing lebih rapat tapi tetap lega
- gunakan ritme visual yang konsisten

## Card system
### Featured case study card
- besar
- dua kolom
- editorial feel
- ada visual block
- ada metadata ringkas

### Metric card
- kecil
- angka jadi fokus utama
- mono label

### Support card
- untuk experience highlights dan credibility
- lebih sederhana

## Warna
Gunakan pendekatan warna berikut:
- neutral premium base
- high contrast text
- satu accent color untuk CTA, metric highlights, dan tags
- permukaan bersih dengan border halus

Rekomendasi arah warna:
- background: off-black atau warm white
- surface: neutral slightly elevated
- accent: electric blue, deep cyan, atau muted lime

## Motion
- low-motion only
- fade-up ringan
- hover lift ringan
- underline motion halus pada link

## Jangan gunakan
- gradient fog berlebihan
- floating blobs
- glassmorphism berat
- parallax aneh
- terminal intro palsu
- skill icons beterbangan
- style gaming neon berlebihan

## Karakter visual homepage
### Hero
- headline kuat di kiri
- proof panel di kanan
- CTA jelas
- tidak terlalu dekoratif

### Featured projects
- tampak seperti preview case study, bukan card gallery biasa
- boleh pakai architecture thumbnail
- metadata singkat, tidak ramai

### Case study page
- struktur konten jelas
- technical labels konsisten
- bukti visual dipakai seperlunya
- nada visual serius dan sistematis
