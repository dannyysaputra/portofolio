# 08_REFINEMENT_PROMPT.md

Gunakan prompt ini setelah agent menghasilkan versi pertama.

```text
Refine the portfolio website you just created.

Now improve it with these priorities:
- make the homepage feel more premium and less template-like
- strengthen typography hierarchy
- improve project card composition so each featured project feels like a case study preview, not a generic card
- improve spacing and rhythm between sections
- make the proof strip feel more credible and editorial
- make the case study pages feel more technical and evidence-based
- reduce any visual noise
- remove anything that feels generic, startup-landing-page-like, or overly decorative
- improve mobile responsiveness
- improve CTA clarity
- keep the site readable and professional

Then:
- rewrite any weak copy
- improve component polish
- tighten interaction design
- simplify anything cluttered
- keep the design system consistent
- preserve the project-first positioning

Important:
- Do not rewrite the site into a generic SaaS landing page
- Do not add decorative effects that hurt readability
- Do not make biography more dominant than projects
- Do not overuse gradients, icons, or animation
```
