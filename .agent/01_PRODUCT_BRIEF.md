# 01_PRODUCT_BRIEF.md

## Product goal
Membangun web portfolio baru untuk software developer dengan orientasi utama pada **showcase project** dan **case study teknis**.

Website harus menjadi alat evaluasi kemampuan, bukan sekadar kartu nama digital.

## Audience utama
- recruiter
- CTO
- engineering manager
- founder
- technical interviewer
- client potensial

## Positioning utama
**Backend-focused engineer building real products with AI, APIs, and production-ready systems.**

## Core message
Dalam 5 detik pertama, pengunjung harus paham bahwa pemilik portfolio:
- kuat di backend dan API systems
- mampu mengerjakan end-to-end delivery
- menggunakan AI secara praktis, bukan sekadar gimmick
- punya bukti hasil nyata dari project

## Portfolio principles
1. Projects are the main argument.
2. Evidence beats self-description.
3. Technical depth must remain readable.
4. Visual uniqueness must not reduce credibility.
5. Skills support projects, not the opposite.

## Site priorities
Urutan prioritas isi situs:
1. featured projects
2. proof and outcomes
3. technical thinking
4. credibility signals
5. short profile
6. contact CTA

## Tone dan style
- tajam
- profesional
- ringkas
- teknis
- tidak pamer berlebihan
- tidak generik

## Yang harus dihindari
- skill wall besar
- progress bar skill
- certificate-heavy homepage
- timeline hidup panjang
- visual yang terlalu startup landing page
- copy seperti “I am passionate about technology”

## Featured projects utama
1. **AI Screening Service**
2. **Arabicara**
3. **Kasep**

Ketiga project ini dipilih karena paling kuat dalam kombinasi:
- backend thinking
- applied AI
- measurable outcome
- produk nyata
- technical storytelling
