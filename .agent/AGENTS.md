# AGENTS.md

Dokumen ini adalah titik masuk utama untuk agent yang akan membangun ulang web portfolio.

## Tujuan utama
Bangun portfolio web baru yang **project-first**, **backend-focused**, **unik secara visual**, **profesional**, dan **siap dipakai untuk melamar kerja**.

Fokus utama bukan biodata. Fokus utama adalah **case study project** yang menunjukkan:
- problem
- context
- constraints
- role
- solution
- technical decisions
- trade-offs
- outcomes
- proof

## Posisi utama pemilik portfolio
**Backend-focused software engineer who ships end-to-end products with AI, strong API design, and production-minded architecture.**

Narasi utamanya:
> Saya paling kuat di backend architecture dan API systems. Saya juga bisa membangun layer frontend jika dibutuhkan, dan saya menggunakan AI saat itu benar-benar memberi nilai produk.

## Urutan file yang wajib dibaca agent
Baca file berikut dalam urutan ini:

1. `01_PRODUCT_BRIEF.md`
2. `02_INFORMATION_ARCHITECTURE.md`
3. `03_CASE_STUDY_SYSTEM.md`
4. `04_VISUAL_DIRECTION.md`
5. `05_BUILD_SPEC.md`
6. `06_CONTENT_INPUT_TEMPLATE.md`
7. `07_MASTER_BUILD_PROMPT.md`
8. `08_REFINEMENT_PROMPT.md`

## Aturan penting
- Jangan buat portfolio generik ala template.
- Jangan buat homepage yang terlalu banyak badge stack.
- Jangan jadikan biography sebagai pusat situs.
- Jangan menampilkan semua project seolah-olah nilainya sama.
- Jangan gunakan hero yang penuh gradient, floating blob, terminal palsu, atau animasi berlebihan.
- Jangan gunakan copy generik seperti “passionate developer”.
- Jangan mengarang metrik, testimonial, perusahaan, atau hasil yang tidak diberikan.

## Deliverable minimum
Agent harus menghasilkan:
- homepage lengkap
- 3 halaman case study project
- komponen reusable
- data/content structure yang mudah diedit
- layout responsif
- CTA yang jelas
- styling yang konsisten

## Tech stack wajib
- Next.js
- TypeScript
- Tailwind CSS
- App Router
- Component-based architecture

## Design direction singkat
Gunakan gaya **Editorial Technical Case Study**:
- typography kuat
- ruang yang lega
- layout editorial asimetris yang tetap rapi
- elemen dekoratif minimal
- bukti, metrik, dan system notes menjadi bagian visual utama

## Prioritas implementasi
1. Hero
2. Proof strip
3. Featured project cards
4. Full case study pages
5. Technical strengths
6. Trust signals
7. Contact CTA

## Hasil yang diharapkan
Portfolio harus terasa:
- tajam
- teknis
- meyakinkan
- berbeda dari portfolio developer umum
- tetap mudah dibaca recruiter dan technical lead
