## Penjelasan section homepage

### Hero
**Goal:** menetapkan positioning dalam beberapa detik.

**Harus berisi:**
- nama
- positioning headline
- subheadline
- supporting credibility line
- CTA utama
- visual proof panel

**Hindari:**
- foto besar yang tidak membantu
- stack badges bertumpuk
- animasi berat
- intro panjang

### Proof Strip
**Goal:** menunjukkan bukti cepat.

**Harus berisi:**
- 3 sampai 4 hard metrics
- outcome singkat
- label yang jelas

**Contoh isi:**
- 90% relevance scoring
- 80% manual work reduction
- near-100% data accuracy
- Top 100 recognition

### Selected Case Studies
**Goal:** menjadikan project sebagai pusat portfolio.

**Harus berisi:**
- 3 project unggulan saja
- problem
- solution
- impact
- architecture hint
- CTA ke detail

### Production Experience Highlights
**Goal:** menunjukkan pengalaman sistem nyata di luar project utama.

**Harus berisi:**
- Kafka microservices
- SIMRS integration
- IoT/backend production work
- event-driven backend notes

### About / Profile
**Goal:** memberi konteks singkat tanpa menggeser fokus project.

**Harus berisi:**
- cara kerja
- tipe masalah yang disukai
- kecenderungan teknis
- 1 paragraf ringkas

### Technical Strengths
**Goal:** merangkum capability secara terstruktur.

**Gunakan grup berikut:**
- Backend Systems
- Frontend Delivery
- Applied AI
- Deployment and Ops

### Credibility / Trust Signals
**Goal:** mengurangi risk perception.

**Isi yang bisa dipakai:**
- Top 100 Google Solution Challenge
- Top 13 dari 650+ tim di Hackfest
- Kafka microservices
- SIMRS dan lab integration
- RHCSA jika relevan

### Contact CTA
**Goal:** mengubah perhatian menjadi aksi.

**Harus berisi:**
- CTA yang tegas
- email
- GitHub
- LinkedIn
- CV link
