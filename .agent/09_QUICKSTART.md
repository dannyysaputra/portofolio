# 09_QUICKSTART.md

## Cara pakai cepat

### Opsi 1: Untuk agent coding / builder
1. Taruh semua file markdown ini di root workspace.
2. Pastikan file `AGENTS.md` ikut terbaca.
3. Isi `06_CONTENT_INPUT_TEMPLATE.md` dengan data asli.
4. Jalankan agent menggunakan isi `07_MASTER_BUILD_PROMPT.md`.
5. Setelah hasil pertama jadi, gunakan `08_REFINEMENT_PROMPT.md`.

### Opsi 2: Untuk Cursor / Claude Code / agent lokal
- buka workspace
- pastikan agent membaca `AGENTS.md`
- minta agent membaca semua markdown terkait
- minta agent membangun codebase sesuai `05_BUILD_SPEC.md`

### Opsi 3: Untuk v0 / Lovable / Bolt
- copy isi `07_MASTER_BUILD_PROMPT.md`
- tambahkan data pribadi dan project
- jika hasil terlalu generik, lanjutkan dengan isi `08_REFINEMENT_PROMPT.md`

## Saran workflow
1. Isi data project asli dulu.
2. Bangun homepage dan 3 case study page.
3. Review copy dan layout.
4. Baru poles visual detail.
